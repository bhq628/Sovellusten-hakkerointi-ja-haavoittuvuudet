## b) Make a new version of the passtr.c program where the password doesn't appear directly as-is in the binary. Demonstrate with a test that the password doesn't appear. (Obfuscation is sufficient.)  

Aloitan tästä. Se on tiedosto "passtr.c" nano tekstieditorissa.  
Tässä vaiheessa tiedostoa ei olla muokattu.  

> **Note:** Gemini 3.5 Flash ymmärrys koodista rivi riviltä:  
> #include <stdio.h>: Ottaa mukaan standardikirjaston syöte- ja tulostustoiminnot (kuten printf ja scanf).  
>  
>  #include <string.h>: Ottaa mukaan merkkijonojen käsittelykirjaston (kuten strcmp).  
>  
> int main() {: Ohjelman pääfunktio, josta ohjelman suoritus alkaa.  
> 
> char password[20];: Varaa muistista 20 tavun kokoisen merkkijonotaulukon käyttäjän salasana-syötettä varten.  
> 
> printf("What's the password?\n");: Tulostaa päätteelle tekstin, joka kysyy salasanaa.  
> 
> scanf("%19s", password);: Lukee käyttäjältä syötteen ja tallentaa sen password-muuttujaan rajoittaen merkkien määrän turvallisesti enintään 19 merkkiin.  
> 
> if (0 == strcmp(password, "sala-hakkeri-321")) {: Vertaa käyttäjän syöttämää merkkijonoa kovakoodattuun salasanaan "sala-hakkeri-321". Jos ne ovat täsmälleen samat, strcmp palauttaa nollan.  
> 
> printf("Yes! That's the password. FLAG{...}\n");: Tulostaa onnistumisviestin ja lipun (flag), jos salasana oli oikein.  
> 
> } else {: Määrittelee vaihtoehtoisen haaran, jos annettu salasana oli väärä.  
> 
> printf("Sorry, no bonus.\n");: Tulostaa ilmoituksen väärästä salasanasta.  
> 
> }: Sulkee if-else-rakenteen.  
> 
> return 0;: Palauttaa arvon 0 käyttöjärjestelmälle merkiksi siitä, että ohjelma suorittautui onnistuneesti loppuun.  
> 
> }: Sulkee pääfunktion (main).
